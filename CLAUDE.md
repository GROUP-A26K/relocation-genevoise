1. Récupère le contenu de `claude-config` (clone ou lecture via `gh`) :
   `gh repo clone GROUP-A26K/claude-config /tmp/claude-config -- --depth 1`
   ou, si déjà présent : `git -C /tmp/claude-config pull`.
2. Lis `/tmp/claude-config/CLAUDE.md` et suis sa section « Chargement obligatoire ».
3. Lis `/tmp/claude-config/projects/relocation-genevoise/claude.md`.
4. Applique les règles `shared/*` pertinentes selon la table de routage.

Si tu ne peux pas accéder au repository `claude-config`, arrête-toi et dis-le : ne travaille
pas sans ces instructions.
